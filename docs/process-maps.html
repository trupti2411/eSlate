Admin — Features Built vs. Needed

✓ Built & Working

✓Dashboard — live user/business/class/invite counts
✓List all users with role + company filter
✓Invite multi-tutor business owner — creates business + token + email
✓Academic years, terms, subjects CRUD (Laravel)
✓NSW State Packs — curriculum data (GET + apply)
✓View audit logs per company / user
✓Tier enforcement: individual→1, starter→5, pro→20, enterprise→∞
✓Worksheet management + editor
✓Support contacts management (add / remove / list)
✓Company settings CRUD
✓WWCC compliance visibility via tutor records

✗ Needs to Be Built

✗User status toggle — is_active col missing; endpoint returns 422. Critical fix.
✗Billing & subscription management — no Stripe or payment integration
✗Global compliance dashboard — all tutors' WWCC across all businesses
✗Platform-wide analytics — cross-business trends, DAU/MAU
✗System health monitoring — API errors, DB pool, uptime
✗Global broadcast notifications to all businesses/tutors
✗Global course template library (platform-owned)
✗Admin impersonation — log in as any user for support
✗Tier upgrade/downgrade UI — currently manual
✗Bulk user import via CSV
~Platform reports — per-company only; no aggregate cross-business view
⚠️
Critical fix: PATCH /api/admin/users/{user}/status fails 422 — is_active column missing from PostgreSQL users table. One migration, 30-minute fix.

Tutoring Business — Features Built vs. Needed

✓ Built & Working

✓Token-based business onboarding (invite → accept → profile)
✓Business profile — logo, ABN, timezone, currency
✓Active subject management (toggle from master list)
✓Academic years + terms CRUD
✓Classes — create, schedule, assign tutor, capacity, conflict detection
✓Enrol / unenrol students in classes
✓Course catalogue — courses + offerings (year × subject × level)
✓Enrol / withdraw students from course offerings
✓Invite tutors — placeholder user + tutor row + email
✓WWCC compliance tracking per tutor (number, expiry, state, status)
✓Add students (record-only, no login required initially)
✓Assignment creation — file-upload or worksheet type
✓File upload to GCS (multer, max 30 MB, PDF/img/doc)
✓View all submissions (by class or business-wide)
✓PDF marking — pen annotation, tick/cross, page rotation
✓AI grading: Gemini → Groq → GPT-4o fallback chain
✓Score + written feedback + reviewer annotations per submission
✓Parent email on graded submission
✓6 report types + ad-hoc + scheduled runs + CSV/PDF/XLSX export
✓Audit log (all key business actions tracked)
✓Tier enforcement + weekly timetable view

✗ Needs to Be Built

✗Billing & payment integration — no Stripe or invoice generation
✗Real-time messaging — no WebSocket; polling only
✗Calendar sync — no Google Calendar / Outlook integration
✗Automated student progress PDF per student per term
✗Resource / material library — shared file store per business
✗Mobile app (iOS / Android)
✗Live online class / video integration (Zoom / Meet)
✗Tutor payroll / invoicing — hours → pay calculations
✗Enrolment trends report — schema exists, runner not wired
✗Parent self-registration / invite flow
✗Push notifications (browser / mobile)
✗Bulk student import via CSV
✗Multi-branch management UI (branch field on tutors exists)
~Attendance marking UI — classSessions + sessionAttendance tables built; front-end not wired
~Holiday / calendar events — tables built; admin form incomplete
~Notification preferences — schema built; UI trigger coverage partial
